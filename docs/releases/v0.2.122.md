# 红果短剧 v0.2.122

修复 webOS 播放接手后台预加载时，上游临时请求失败会直接显示无法播放、需要手动重试的问题。

- 当播放正在等待同一集的后台预加载、且遇到临时取源错误时，自动恢复一次；同一集的并发请求共享恢复结果，避免重复请求。
- 离开播放页或取消等待时停止恢复；鉴权、参数等明确错误不自动重试，持续失败仍正常报告错误。
- 保留现有 Range/CENC 边下载、边解密、边播放方式及上一版 HTTP 响应修复；有声倍速实验选项继续默认关闭。
- 新增 15 项回归，覆盖真实 HTTP 断连、页面 1.2 秒预加载接手、并发、取消及重试上限；修复后的压缩 IPK 回归通过，LG 真机实际改善待新版测试。
- Android、macOS 和 Windows 同步统一主线版本，本轮未修改这些平台的播放逻辑。

## 平台包

- Android 标准版：`hongguo-tv-0.2.122.apk`（versionCode 123）
- Android MPV 版：`hongguo-tv-mpv-0.2.122.apk`（versionCode 75）
- macOS / Windows：`hongguo-desktop-0.2.122-macos-universal.zip`、`hongguo-desktop-0.2.122-windows-x64.zip`
- Linux x86_64 AppImage：继续提供 `linux-v0.2.120-test.1`；新包仅在 Ubuntu 24.04 与 Debian 12 验证通过后发布。
- LG webOS：`webos-v0.2.122-test.25` 测试版，通过 webOS Dev Manager 手动更新 IPK。

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。Android 标准版和 MPV 版保持各自原有包名、签名和更新渠道。
