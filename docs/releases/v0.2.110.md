# 红果短剧 v0.2.110

## 修复

- 修复 Android 播放时屏幕常亮状态只跟随单次播放回调的问题。
- 播放进入后台时释放窗口常亮标志，返回前台时按仍在播放的状态自动恢复，避免短暂切后台后屏幕意外熄灭。
- 标准版与 MPV 版统一在播放、暂停、结束、错误和切换播放源时同步屏幕常亮状态。

## 平台包

- Android 标准版：`hongguo-tv-0.2.110.apk`（versionCode 111）
- Android MPV 版：`hongguo-tv-mpv-0.2.110.apk`（versionCode 63）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.110-macos-universal.zip`、`hongguo-desktop-0.2.110-windows-x64.zip`（versionCode 49）
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 与 webOS 仍属于平台测试包，实际兼容性取决于目标设备运行库、解码能力和型号。
