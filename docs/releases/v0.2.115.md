# 红果短剧 v0.2.115

## Android 标准版 HEVC 回退

- 当 Media3 选中的 HEVC 轨道超出设备解码能力且尚未显示首帧时，Android 标准版会在当前播放会话内尝试平台软件 HEVC 解码器。
- 回退只针对当前播放会话，不会修改全局解码设置；诊断区分回退请求与实际初始化的软件解码器。
- Android MPV、桌面、Linux 和 webOS 的播放逻辑没有改变；各平台仍按统一发布线重新构建。

## 平台包

- Android 标准版：`hongguo-tv-0.2.115.apk`（versionCode 116）
- Android MPV 版：`hongguo-tv-mpv-0.2.115.apk`（versionCode 68）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.115-macos-universal.zip`、`hongguo-desktop-0.2.115-windows-x64.zip`
- Linux x86_64 AppImage 测试版：独立预发行包
- LG webOS 实验版：`hongguo-webos-0.2.115-test.25.ipk`

Windows 播放 HEVC 视频需要安装 [HEVC Video Extensions](https://github.com/Ayx03/HEVCVideoExtension)。Linux AppImage 和 webOS 仍是平台测试包，发布包不代表已在所有目标设备上完成实机播放验证。
