# 红果短剧 v0.2.121

修复 webOS 视频 Range 响应未结束的问题：客户端收到一段数据后，复用同一 HTTP 连接的后续媒体请求可能被阻塞，导致播放停住。

- 视频范围数据写完后正确结束响应，恢复连接复用与在途读取保护的释放，保留现有边下载、边解密、边播放机制。
- 新增连续六次复用同一连接的实际 HTTP 回归，覆盖前缀探测、CENC 解密、HEAD、完整响应、多块背压和后续尾段读取。正式 0.2.120 IPK 可复现阻塞，修复后的压缩 IPK 回归通过。
- webOS 有声倍速实验选项继续默认关闭。LG C1 用户“卡在第一帧”的实际改善仍待新版电视测试。
- Android、macOS 和 Windows 同步统一主线版本，Linux 继续提供已发布测试包。

## 平台包

- Android 标准版：`hongguo-tv-0.2.121.apk`（versionCode 122）
- Android MPV 版：`hongguo-tv-mpv-0.2.121.apk`（versionCode 74）
- macOS / Windows：`hongguo-desktop-0.2.121-macos-universal.zip`、`hongguo-desktop-0.2.121-windows-x64.zip`
- Linux x86_64 AppImage：沿用 `linux-v0.2.120-test.1` 预发行版
- LG webOS：`webos-v0.2.121-test.25` 测试版，通过 webOS Dev Manager 手动更新 IPK。

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。Android 标准版和 MPV 版保持各自原有包名、签名和更新渠道。
