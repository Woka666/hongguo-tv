# 红果短剧 v0.2.125

统一发布 Android、macOS、Windows、Linux AppImage 和 LG webOS 测试包。播放取源改用已验证的匿名注册设备和新的多集片源接口，修复部分集数无法取得播放源的问题。

- 播放首次使用匿名设备注册，当前运行期复用设备身份；注册失败后点击重试即可重新注册，不需要重启应用。
- Go 核心和 webOS Service 使用 `/novel/player/multi_video_model/v1/`，兼容清晰度对象/数组格式、备用片源地址和旧格式 `fallback_api`。
- 备用接口仅允许 HTTPS 及红果受信任域名，并限制响应大小、重定向次数和请求时长。
- 保留 Range/CENC 按需读取、边播边下、媒体缓存和 webOS 单播放器预取交接逻辑。
- 浏览器真实数据环境已验证切集和换片可正常播放；Android、桌面和 webOS 的自动化回归及构建检查通过。LG 实机解码仍需在目标电视上验收。

## 平台包

- Android 标准版：`hongguo-tv-0.2.125.apk`（versionCode 124）
- Android MPV 版：`hongguo-tv-mpv-0.2.125.apk`（versionCode 76）
- macOS / Windows：`hongguo-desktop-0.2.125-macos-universal.zip`、`hongguo-desktop-0.2.125-windows-x64.zip`
- Linux x86_64 AppImage：`linux-v0.2.125-test.1` 预发行版
- LG webOS：`webos-v0.2.125-test.25` 测试版

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。Android 标准版和 MPV 版保持各自原有包名、签名和更新渠道。
