# 红果短剧 v0.2.118

本次为 LG webOS 加入在线版本检查与手动安装指引，Android、macOS、Windows 和 Linux 同步统一版本。

## webOS 更新

- 设置中新增“检查更新”，展示当前版本、新版本说明、发布页地址和 webOS Dev Manager 安装方法。
- 每天最多自动检查一次；发现新版时在非播放状态提醒，同一版本只提醒一次，操作焦点保持不变。
- 支持内置代理线路，全部失败后回退 GitHub 直连；检查失败可手动重试，并保留已知的新版本信息。
- 仅检查并提示，不会自动下载或安装 IPK。旧版用户需先手动安装 0.2.118，才可检查后续新版本。

## 平台包

- Android 标准版：`hongguo-tv-0.2.118.apk`（versionCode 119）
- Android MPV 版：`hongguo-tv-mpv-0.2.118.apk`（versionCode 71）
- macOS / Windows：`hongguo-desktop-0.2.118-macos-universal.zip`、`hongguo-desktop-0.2.118-windows-x64.zip`
- Linux x86_64 AppImage：`linux-v0.2.118-test.1` 预发行版
- LG webOS：`webos-v0.2.118-test.25` 测试版

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。Android 标准版和 MPV 版保持各自原有包名、签名和更新渠道。
