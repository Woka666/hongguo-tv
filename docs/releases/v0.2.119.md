# 红果短剧 v0.2.119

本次主要优化 LG webOS 的切集准备与旧版浏览器兼容，Android、macOS、Windows 和 Linux 同步统一主线版本及共享播放诊断。

## webOS 更新

- 下一集预取失败后，在稳定播放时隔至少 3 秒重试一次；长集剩余 30 秒以内可刷新过期准备结果，与失败重试共用一次额外尝试额度。
- 前台播放与后台预取共用取源和 Range 初始化任务，减少切集时重复准备；超过 2 分钟的准备结果重新解析、校验。
- 修复 webOS 6 / Chrome 79 缓存会话请求的 keepalive 跨域预检错误。
- 播放诊断显示接口解析、Range 索引、完整文件回退下载和解密耗时；切集仍保留上一集画面时，读取当前前台准备信息。

webOS 继续优先使用 Range 按需下载、解密和播放，并保留兼容性回退。真实接口的并发准备复用、缓存命中和视频分段读取检查已通过；新包在 LG 电视上的切集耗时需要实机反馈。

## 平台包

- Android 标准版：`hongguo-tv-0.2.119.apk`（versionCode 120）
- Android MPV 版：`hongguo-tv-mpv-0.2.119.apk`（versionCode 72）
- macOS / Windows：`hongguo-desktop-0.2.119-macos-universal.zip`、`hongguo-desktop-0.2.119-windows-x64.zip`
- Linux x86_64 AppImage：`linux-v0.2.119-test.1` 预发行版
- LG webOS：`webos-v0.2.119-test.25` 测试版；支持检查新版提示，通过 webOS Dev Manager 手动安装 IPK。

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。Android 标准版和 MPV 版保持各自原有包名、签名和更新渠道。
