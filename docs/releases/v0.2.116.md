# 红果短剧 v0.2.116

## 搜索连接与分页

- 修复首次设备注册连接失败时，搜索直接报错、无法使用备用接口的问题（Issue #52）。Android 标准版、MPV 版及 macOS、Windows、Linux 的共享 Go 核心现在会在首屏注册或 App 搜索失败后，尝试官网免登录 JSON 搜索。
- 官网备用搜索支持连续翻页，不再依赖搜索页面中的 `_ROUTER_DATA`，也不再把联想建议当作完整搜索结果。后续页固定使用首屏选定的来源；翻页失败保留已加载卡片，重试同一页。
- 官网网络或 HTTP 5xx 失败最多重试一次；需要图形验证、返回错误页面等情况会明确报错。联想建议、输入焦点和播放器逻辑保持原样。

## 平台包

- Android 标准版：`hongguo-tv-0.2.116.apk`（versionCode 117）
- Android MPV 版：`hongguo-tv-mpv-0.2.116.apk`（versionCode 69）
- macOS / Windows：`hongguo-desktop-0.2.116-macos-universal.zip`、`hongguo-desktop-0.2.116-windows-x64.zip`
- Linux x86_64 AppImage：`linux-v0.2.116-test.1` 预发行版
- LG webOS：`webos-v0.2.116-test.25` 实验版；其独立 JavaScript 服务此次仅同步版本并重建，不包含上述 Go 搜索修复。

验证包含真实匿名官网搜索连续两页及注册失败回退回归，尚未在 Issue #52 用户的 Linux 机器上复测。官网仍可能因网络或验证要求而暂时不可用。

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。Linux 和 webOS 仍是平台测试包。Issue #54 的 HEVC 硬解右缘绿条本次尚未修改，可继续使用已验证有效的 MPV 软件解码设置。
