# 红果短剧 v0.2.111

## 修复

- 修复部分搜索请求返回空响应时错误进入网页解析，导致显示“页面缺少 `_ROUTER_DATA`”。
- 搜索失败时优先使用红果搜索建议接口恢复可播放的短剧结果；只有建议接口没有可用作品时才继续尝试网页搜索。
- 搜索失败后的“重试”按钮接入搜索输入、搜索操作和筛选区的焦点路径。
- 桌面版联想浮层支持按 Esc 关闭；输入框可用方向键进入建议列表或搜索按钮，文字编辑中的左右方向键仍保留原生光标行为。

## 平台包

- Android 标准版：`hongguo-tv-0.2.111.apk`（versionCode 112）
- Android MPV 版：`hongguo-tv-mpv-0.2.111.apk`（versionCode 64）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.111-macos-universal.zip`、`hongguo-desktop-0.2.111-windows-x64.zip`（versionCode 50）
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 与 webOS 仍属于平台测试包，实际兼容性取决于目标设备运行库、解码能力和型号。
