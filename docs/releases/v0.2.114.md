# 红果短剧 v0.2.114

## 播放器回退

- Android 标准版继续默认使用 HTML5；明确媒体错误或非自动播放策略类 `play()` 失败时，立即尝试 Media3。`NotAllowedError` 和播放中断不触发回退。
- 没有明确错误时，HTML5 有可观察进展就继续等待；零进展 1.8 秒后切换。收到 `playing` 但仍未出首帧时，另等 3 秒再切换。这些时限是首轮验证值，后续按设备诊断调整。
- 只有 HTML5 解码/格式失败，且 Media3 已真实渲染首帧后，才在本机记录 Media3 优先路径；记录 30 天有效，并在 WebView 版本变化时失效。网络错误和超时不会写入偏好。
- Media3 失败时停止原播放器并从原位置回到 HTML5 重试；单集播放过程中最多自动切换一次。诊断显示播放器路径、切换原因和阶段耗时，不上传数据。
- Android MPV 版继续使用 MPV 固定路径；桌面、Linux 和 webOS 的播放器选择不变。

- Android 标准版：`hongguo-tv-0.2.114.apk`（versionCode 115）
- Android MPV 版：`hongguo-tv-mpv-0.2.114.apk`（versionCode 67）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.114-macos-universal.zip`、`hongguo-desktop-0.2.114-windows-x64.zip`（desktop versionCode 53）
- Linux x86_64 AppImage 测试版：在 Ubuntu 24.04 和 Debian 12 对本次产物重新验证
- LG webOS 实验版：`hongguo-webos-0.2.114-test.25.ipk`

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 和 webOS 仍是平台测试包；容器或文件级验证不等同于所有目标设备上的真机播放验证。
