# 红果短剧 v0.2.112

## 修复

- 搜索结果统一使用红果 App 搜索接口；匿名搜索会先完成设备注册并保存会话，避免因未注册设备收到空响应。
- 兼容搜索接口返回顶层 `search_tabs` 的新响应结构，保留搜索分页游标和多季结果，修复“加载失败：页面缺少 `_ROUTER_DATA`”。
- 旧版 `/api/v1/search` 路由统一转发到新的搜索列表接口，避免桌面、Android、webOS 使用不同的搜索核心。
- 搜索联想接口和联想浮层行为保持不变，本次没有改动搜索建议。

## 平台包

- Android 标准版：`hongguo-tv-0.2.112.apk`（versionCode 113）
- Android MPV 版：`hongguo-tv-mpv-0.2.112.apk`（versionCode 65）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.112-macos-universal.zip`、`hongguo-desktop-0.2.112-windows-x64.zip`（desktop versionCode 51）
- Linux x86_64 AppImage 测试版
- LG webOS 实验版：`hongguo-webos-0.2.112-test.24.ipk`

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 与 webOS 仍属于平台测试包，实际兼容性取决于目标设备运行库、解码能力和型号。
