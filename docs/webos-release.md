# 红果短剧 webOS 测试版 0.2.121

修复视频 Range 服务发送完请求范围后没有结束 HTTP 响应的问题。客户端复用同一连接继续读取媒体时，后续响应可能被堵住，使播放停在开头画面。

- 范围数据全部写完后正确结束响应，并释放该次在途读取保护。
- 保留原有 Range 按需下载、解密及切集机制。
- 实际 HTTP 连续请求与压缩 IPK 回归通过，覆盖 CENC、HEAD、完整响应、多块背压及后续范围读取。

LG C1 用户反馈的实际改善仍待新版电视实测。原有“有声倍速（实验）”选项继续默认关闭，可在设置中、版本更新上方开启；LG 真机上的倍速声音性能、听感和长时间同步仍待验证。

支持设置内在线检查更新及内置代理线路。应用仅检查并提示，不自动下载或安装 IPK；请启用电视 Developer Mode，通过 webOS Dev Manager 或 webOS 开发工具安装新版。
