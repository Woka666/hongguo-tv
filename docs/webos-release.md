# 红果短剧 webOS 测试版 0.2.123

本版把 Mac 播放器验证过的“下一集提前准备”思路移植到 webOS HTML5 播放路径，减少切集时重复加载、黑屏和长时间等待。

- 播放稳定约 1.5 秒后，后台获取下一集并用隐藏、静音的 HTML5 video 预热媒体。
- 切集时接管已经预热的 video，保留已有缓冲，不重复设置 `src` 或调用 `load()`。
- 预热失败、取消或长时间未使用时自动清理隐藏播放器，不持续占用资源。
- 保留现有 Range 按需下载、解密、切集、重试、缓存和 HTTP 响应修复。
- webOS 有声倍速实验继续隐藏并固定为 1 倍速，避免影响播放稳定性。
- 17 项回归覆盖预热接管、失败清理、真实 HTTP 断连、并发、取消及重试上限，压缩 IPK 回归通过。

LG 真机实际改善仍待新版测试。

支持设置内在线检查更新及内置代理线路。应用仅检查并提示，不自动下载或安装 IPK；请启用电视 Developer Mode，通过 webOS Dev Manager 或 webOS 开发工具安装新版。
